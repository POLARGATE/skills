# Skills de Polargate para Claude Code

Las skills que usamos a diario en Polargate para construir software con IA. Gratis y con licencia MIT.

Te conectas una vez y cada mejora que subimos te llega sola.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
```

Y después instala las que quieras, por ejemplo:

```
/plugin install agentic-build-review-loop@polargate
```

Para recibir las mejoras: `/plugin marketplace update polargate`.

## Qué hay

| Skill | Para qué sirve |
|---|---|
| [agentic-build-review-loop](plugins/agentic-build-review-loop) | Un cerebro construye y otro revisa antes de aceptar nada. Para Claude Code, Lovable, Cursor o Codex. |
| [cto-product-review](plugins/cto-product-review) | Revisa un plan, un prompt o una pantalla como lo haría un CTO: arquitectura, UX/UI, accesibilidad y producción. |
| [autopilot](plugins/autopilot) | Trabaja solo en lo reversible, para en lo irreversible y te entrega un resumen. Se enciende diciendo "autopilot on". |
| [capacitor-store-release](plugins/capacitor-store-release) | Publicar apps de Vite, React y Capacitor en App Store y Google Play sin rechazos. |
| [brand-mark-svg](plugins/brand-mark-svg) | Logos y símbolos de marca en SVG limpio, con todas sus versiones. |
| [seo-geo](plugins/seo-geo) | SEO técnico, Core Web Vitals, datos estructurados y aparecer en las respuestas de las IA. |

Están escritas en inglés porque Claude las sigue mejor así. Te contestan en tu idioma.
