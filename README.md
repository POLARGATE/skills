# Skills de Polargate para Claude Code

Las skills que usamos a diario en Polargate para construir software con IA. Gratis y con licencia MIT.

Te conectas una vez y cada mejora que subimos te llega sola.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
```

Y después instala las que quieras, por ejemplo:

```
/plugin install agentic-build-review-loop@polargate
```

Para recibir las mejoras: `/plugin marketplace update polargate`.
