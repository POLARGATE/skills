# Escribe en LinkedIn sin que se note la IA

Para que tus posts digan algo tuyo y suenen a ti.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-escribe-en-linkedin@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-escribe-en-linkedin?utm_source=github&utm_medium=readme).
