# polargate-resume-reuniones

Claude te responde con lo que se dijo en tus reuniones, no con lo que le suena.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-resume-reuniones@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-resume-reuniones?utm_source=github&utm_medium=readme).
