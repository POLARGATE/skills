# polargate-haz-reels

Para que Claude te haga reels de texto animado sin cámara ni editor de vídeo.

También trae PolarMotion, de Polargate: 66 estilos de vídeo hechos con código. La skill la descarga de [POLARGATE/polarmotion](https://github.com/POLARGATE/polarmotion), en una versión fija, y solo cuando la persona lo acepta.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-haz-reels@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-haz-reels?utm_source=github&utm_medium=readme).

Los avisos de licencia están en `LICENSE` y `NOTICE.md`.
