# polargate-entiende-tu-proyecto

Para que Claude entienda un proyecto grande sin leérselo entero en cada sesión.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-entiende-tu-proyecto@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-entiende-tu-proyecto?utm_source=github&utm_medium=readme).

Los avisos de licencia están en `LICENSE` y `NOTICE.md`.
