# video-con-codigo

Para que Claude te haga reels de texto animado sin cámara ni editor de vídeo.

Basada en [HyperFrames](https://github.com/heygen-com/hyperframes), de HeyGen, con licencia Apache-2.0, a partir del commit `618c486734b3cbb697bd432bace7e9642e48b6be`. El texto de esta skill es nuestro: explica cómo usar HyperFrames y no copia su código ni sus guías. Incluye estilos adaptados de [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15), de Vincentwei1021, con licencia MIT.
