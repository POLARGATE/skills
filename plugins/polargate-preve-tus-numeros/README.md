# Prevé tus ventas con tu propio Excel

Para saber por dónde irán tus ventas, reservas o gastos.

Basada en [TimesFM](https://github.com/google-research/timesfm), de Google Research, con licencia Apache 2.0, a partir del commit `e51928e`. Cambiamos: guía en español, reglas propias y solo el modelo 2.5. Se instala desde nuestra copia, POLARGATE/timesfm. Los cambios están en el fichero NOTICE de la skill.
