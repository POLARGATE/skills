# Haz que Claude programe con orden

Para que no se lance a escribir código sin pensar.

Basada en [agent-skills](https://github.com/addyosmani/agent-skills), de Addy Osmani, con licencia MIT, a partir del commit `301b02b12bff`. Cambiamos: Un índice en español que dice qué guía usar en cada momento, las reglas de Polargate y los enlaces arreglados. Las guías siguen en inglés, como las escribió su autor.
