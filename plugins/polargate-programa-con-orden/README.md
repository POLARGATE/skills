# Haz que Claude programe con orden

Para que no se lance a escribir código sin pensar.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-programa-con-orden@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-programa-con-orden?utm_source=github&utm_medium=readme).
