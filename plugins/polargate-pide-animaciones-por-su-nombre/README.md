# Pide animaciones y efectos por su nombre

Para explicarle a Claude justo el efecto que tienes en la cabeza.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-pide-animaciones-por-su-nombre@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-pide-animaciones-por-su-nombre?utm_source=github&utm_medium=readme).
