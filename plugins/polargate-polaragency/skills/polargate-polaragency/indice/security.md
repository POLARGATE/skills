# Seguridad: 12 especialistas

Para: revisar riesgos, proteger datos y sistemas. El nombre de cada especialista está en inglés.

| Especialista | Qué hace | Fichero |
|---|---|---|
| AI-Generated Code Security Auditor | Revisa apps hechas con IA buscando claves expuestas, permisos de datos mal puestos y otros fallos típicos, y vuelve a comprobar tras arreglarlos. | `expertos/security/security-ai-generated-code-auditor.md` |
| Application Security Engineer | Hace seguro el desarrollo de software: analiza amenazas, revisa código y forma al equipo para que programe con seguridad. | `expertos/security/security-appsec-engineer.md` |
| Blockchain Security Auditor | Audita contratos inteligentes y aplicaciones blockchain para encontrar fallos que permitan robar fondos, y escribe el informe. | `expertos/security/security-blockchain-security-auditor.md` |
| Cloud Security Architect | Diseña la seguridad de tu nube en AWS, Azure o Google Cloud, con varias capas de defensa y sin confiar en nadie por defecto. | `expertos/security/security-cloud-security-architect.md` |
| Compliance Auditor | Te prepara y acompaña en auditorías de cumplimiento (SOC 2, ISO 27001, HIPAA, PCI-DSS) hasta conseguir la certificación. | `expertos/security/security-compliance-auditor.md` |
| Incident Responder | Actúa ante un ataque o filtración: investiga qué pasó, frena la amenaza, coordina la crisis y evita que se repita. | `expertos/security/security-incident-responder.md` |
| Penetration Tester | Ataca tus sistemas con permiso, simulando a un hacker, para encontrar sus puntos débiles antes que otros. | `expertos/security/security-penetration-tester.md` |
| Secrets & Credential Hygiene Engineer | Gestiona claves y contraseñas de las aplicaciones: las detecta, las guarda a salvo, las renueva y reacciona si se filtran. | `expertos/security/security-secrets-credential-engineer.md` |
| Security Architect | Diseña la seguridad de un sistema desde el principio: analiza amenazas, separa zonas de confianza y revisa riesgos. | `expertos/security/security-architect.md` |
| Senior SecOps Engineer | Revisa cada cambio de código buscando claves y datos sensibles, y comprueba accesos, cookies, cabeceras y registros seguros. | `expertos/security/security-senior-secops.md` |
| Threat Detection Engineer | Crea reglas para detectar ataques en los sistemas de vigilancia (SIEM), busca amenazas y afina las alertas. | `expertos/security/security-threat-detection-engineer.md` |
| Threat Intelligence Analyst | Sigue a los grupos de atacantes, explica sus campañas en informes útiles y crea reglas para detectarlos. | `expertos/security/security-threat-intelligence-analyst.md` |
