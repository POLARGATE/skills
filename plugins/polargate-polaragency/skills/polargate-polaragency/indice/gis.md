# Mapas y datos geográficos: 13 especialistas

Para: mapas, ubicaciones y análisis del territorio. El nombre de cada especialista es el que le puso su autor, en inglés.

| Especialista | Qué hace | Fichero |
|---|---|---|
| 3D & Scene Developer | Crea escenas 3D en la web con terrenos y nubes de puntos que se pueden explorar. | `expertos/gis/gis-3d-scene-developer.md` |
| BIM/GIS Specialist | Conecta los modelos de edificios (Revit, IFC) con los mapas, para planos interiores y gemelos digitales. | `expertos/gis/gis-bim-specialist.md` |
| Cartography Designer | Diseña mapas bonitos y fáciles de leer: colores, letras, etiquetas y mapa base, para impresión o web. | `expertos/gis/gis-cartography-designer.md` |
| Drone/Reality Mapping Specialist | Convierte fotos de dron en mapas, modelos del terreno y modelos 3D listos para usar. | `expertos/gis/gis-drone-reality-mapping.md` |
| GeoAI/ML Engineer | Entrena modelos de IA que detectan objetos y tipos de terreno en imágenes de satélite y aéreas. | `expertos/gis/gis-geoai-ml-engineer.md` |
| Geoprocessing Specialist | Automatiza tareas repetitivas con mapas en ArcGIS Pro mediante scripts y herramientas a medida. | `expertos/gis/gis-geoprocessing-specialist.md` |
| GIS Analyst | Hace el trabajo diario con mapas: crea mapas, gestiona capas, consulta datos y mantiene los datos en orden. | `expertos/gis/gis-analyst.md` |
| GIS QA Engineer | Revisa que los datos de mapas estén bien: sin errores, con metadatos, precisos y en el sistema de coordenadas correcto. | `expertos/gis/gis-qa-engineer.md` |
| Solution Engineer | Monta demos y pruebas de concepto con mapas para comprobar que una idea funciona antes de invertir. | `expertos/gis/gis-solution-engineer.md` |
| Spatial Data Engineer | Limpia y unifica datos geográficos desordenados de cualquier origen y los deja listos para usar. | `expertos/gis/gis-spatial-data-engineer.md` |
| Spatial Data Scientist | Aplica estadística y predicción a datos con ubicación para encontrar patrones que no se ven a simple vista en un mapa. | `expertos/gis/gis-spatial-data-scientist.md` |
| Technical Consultant | Traduce un problema de negocio a una solución con mapas: análisis de carencias, hoja de ruta y respuestas a concursos. | `expertos/gis/gis-technical-consultant.md` |
| Web GIS Developer | Programa aplicaciones web con mapas interactivos y paneles en tiempo real. | `expertos/gis/gis-web-gis-developer.md` |
