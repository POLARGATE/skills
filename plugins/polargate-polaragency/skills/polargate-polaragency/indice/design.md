# Diseño: 10 especialistas

Para: marca, pantallas, experiencia de usuario, imágenes. El nombre de cada especialista es el que le puso su autor, en inglés.

| Especialista | Qué hace | Fichero |
|---|---|---|
| Brand Guardian | Define la identidad de tu marca y vigila que todo lo que publicas sea coherente con ella. | `expertos/design/design-brand-guardian.md` |
| Image Prompt Engineer | Escribe las instrucciones precisas para que una IA genere fotos de calidad profesional. | `expertos/design/design-image-prompt-engineer.md` |
| Inclusive Visuals Specialist | Evita los sesgos de la IA y consigue imágenes y vídeos que representen a las personas con respeto y sin estereotipos. | `expertos/design/design-inclusive-visuals-specialist.md` |
| Persona Walkthrough Specialist | Recorre tu web como lo haría un cliente tipo, anota qué siente en cada punto y te da un informe para vender más. | `expertos/design/design-persona-walkthrough.md` |
| UI Designer | Diseña las pantallas de tu web o app: estilo, componentes y detalles, coherentes con tu marca y fáciles de usar. | `expertos/design/design-ui-designer.md` |
| UI Finish-Gate Reviewer | Revisa las pantallas antes de publicarlas para que no parezcan una plantilla genérica y cumplan lo acordado. | `expertos/design/design-ui-finish-gate-reviewer.md` |
| UX Architect | Deja preparada la base de la web para quien programa: estructura, estilos y guía clara de cómo montarla. | `expertos/design/design-ux-architect.md` |
| UX Researcher | Estudia cómo usa la gente tu producto con pruebas y datos, y te dice qué mejorar para que sea más fácil. | `expertos/design/design-ux-researcher.md` |
| Visual Storyteller | Convierte información compleja en piezas visuales y vídeos que se entienden y conectan con tu audiencia. | `expertos/design/design-visual-storyteller.md` |
| Whimsy Injector | Añade toques de personalidad y detalles divertidos a tu marca para que la recuerden. | `expertos/design/design-whimsy-injector.md` |
