# polargate-mira-tu-seo

Para que Claude te responda de SEO con los números reales de tu web, no con consejos genéricos.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-mira-tu-seo@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-mira-tu-seo?utm_source=github&utm_medium=readme).

Los avisos de licencia están en `LICENSE` y `NOTICE.md`.
