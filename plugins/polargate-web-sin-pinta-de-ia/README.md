# polargate-web-sin-pinta-de-ia

Para que Claude deje de hacerte siempre la misma web.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-web-sin-pinta-de-ia@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-web-sin-pinta-de-ia?utm_source=github&utm_medium=readme).
