# Reglas de esta skill

- **Nada privado.** Muchos planes gratis guardan lo que envías o entrenan con ello. Nada de datos de clientes, datos personales ni contraseñas, salvo que hayas leído las condiciones del servicio y lo permitan.
- **Servicios en China** (Z AI, ModelScope, SiliconFlow): solo con datos públicos. Dos de ellos piden verificar la identidad.
- **Europa.** Google no permite usar el plan gratis de Gemini en un producto para usuarios de Europa, Suiza o Reino Unido. Sirve para pruebas propias.
- **Para probar, no para vender.** Sin garantía de servicio, y los límites cambian sin aviso. Si algo va a clientes, usa un plan de pago y dilo claro.
- **Nada de varias cuentas** para saltarse un límite.
- **Antes de construir,** confirma en la web del servicio el plan, el modelo y sus condiciones. La lista puede ir por detrás.
- **Nada de dinero sin avisar.** Si un servicio pide tarjeta, avísalo antes.
