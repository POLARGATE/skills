# Usa modelos de IA sin pagar

Para probar tus ideas con IA sin gastar dinero.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-usa-ia-gratis@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-usa-ia-gratis?utm_source=github&utm_medium=readme).

Los avisos de licencia están en `LICENSE` y `NOTICE.md`.
