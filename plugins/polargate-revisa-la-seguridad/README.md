# polargate-revisa-la-seguridad

Para saber qué agujeros tiene tu app antes de que los encuentre otro.

## Instalar

En Claude Code:

```
/plugin marketplace add POLARGATE/skills
/plugin install polargate-revisa-la-seguridad@polargate
```

Ficha y guía en la [Biblioteca de Polargate](https://biblioteca.polargate.ai/r/polargate-revisa-la-seguridad?utm_source=github&utm_medium=readme).
